# ظهور عجلة ترحيب Elegance مرة واحدة

تفتح العجلة تلقائيًا مرة واحدة لكل فرصة ترحيب محفوظة في المتصفح، حتى عند إغلاقها دون لف. يبقى زر الهدية متاحًا يدويًا، ويستمر تنبيه اللفة المعلقة عند إرسال الطلب. النتائج الملفوفة لا تتغير عند العودة.

هذا تعريف للزائر من خلال رمز المتصفح، وليس حسابًا موثقًا؛ حذف بيانات المتصفح أو فتح جهاز آخر يُنشئ زائرًا جديدًا. منع صرف هديتين يعتمد على رقم واتساب الطلب ضمن المحل.

إعادة ضبط العجلة تمنح معرف فرصة جديدًا، ولذلك تظهر مرة أخرى حتى في المتصفحات القديمة دون مسح بيانات الموقع أو التطبيقات الأخرى.

## تصفير عجلة Elegance الذي طلبه صاحب الموقع

بعد رفع التعديلات، نفّذ داخل مجلد المشروع على السيرفر:

```sh
git pull --ff-only origin main
php artisan optimize:clear
php artisan shop:reset-customer-registrations elegance-perfumes --wheel-only --execute
```

الأمر يحفظ نسخة احتياطية على قرص Laravel المحلي الخاص تحت `registration-resets/` قبل حذف فرص وجوائز الترحيب وعداداتها لهذا المحل. يحتفظ بالطلبات، وتفاصيل الجوائز المرفقة بالطلبات السابقة، وتسجيلات العملاء، وحسابات الإدارة، وإعدادات الجوائز والمحلات الأخرى. هذا تصفير فعلي لكل جوائز ترحيب المحل، ويسمح لأرقام سبق لها الاستفادة بالحصول على هدية مجددًا.

إذا كانت العجلة غير مفعلة أو توزيعها غير صالح، يظهر تحذير ورابط إعدادات عجلة المحل. التصفير لا يختار جوائز ولا يفعّلها تلقائيًا. حذف `--execute` يعرض الأعداد دون تغيير البيانات.

التحقق: 6 اختبارات JavaScript؛ 28 اختبار PHP و323 تحققًا تشمل التصفير والنسخة الاحتياطية والعزل واستمرار الطلبات. فحص Chrome المحلي تحقق من ظهور أول زيارة، عدم الظهور بعد الإغلاق وإعادة التحميل، وإعادة الفتح من زر الهدية.
