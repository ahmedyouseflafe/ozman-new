# عزل شاشات المحلات

كانت `main_screens` تربط الشاشة بالمستخدم فقط، بينما كانت واجهة أوزمان و`/display` تعرضان جميع الشاشات المفعلة. أصبحت الشاشة مرتبطة بـ`shop_id`، وتقتصر الشاشات العامة على السجلات غير المرتبطة بمحل وغير المنتظرة للتعيين.

- لوحة المحل تستخدم المحل المحدد في الجلسة، أو المحل الوحيد للحساب. الحساب الذي يدير عدة محلات يختار المحل من النموذج.
- صلاحيات الإنشاء والتعديل والحذف تبقى مطلوبة، مع تحقق مستقل من ملكية المحل. صلاحية `screens.view_all` لا توسع نطاق حساب صاحب المحل.
- المدير يستطيع اختيار محل أو واجهة أوزمان العامة صراحة. تعديل الشاشة لا يغير محلها ضمنيًا اعتمادًا على آخر محل مفتوح.
- الشاشات العلوية تدخل عرض المحل مع إعلاناته، والسفلية تظهر أسفل واجهات المحلات المتخصصة. واجهة المتجر العامة تدرج الشاشات ضمن بيانات المحل نفسه.
- حذف محل يحذف سجلات شاشاته؛ لا يحولها إلى شاشات عامة.

## نشر التعديل

بعد رفع الملفات إلى GitHub، نفذ داخل مجلد المشروع على السيرفر:

```sh
git pull --ff-only origin main
php artisan migrate --force --path=database/migrations/2026_10_17_000001_scope_main_screens_to_shops.php
php artisan optimize:clear
```

الترحيل مطلوب قبل اختبار الموقع. يربط الشاشات السابقة بحسابات المحلات عندما يوجد محل واحد فقط مرتبط بالحساب. الشاشات التابعة لحسابات غير إدارية متعددة المحلات أو دون محل تصبح «بانتظار تحديد المحل» ولا تظهر للعامة؛ يمكن اختيار «كل الشاشات المتاحة لحسابي» ثم تعديل الشاشة لتحديد المحل. لا تُحذف ملفاتها ولا تتغير حالة تفعيلها. تبقى شاشات الإدارة العامة والسجلات القديمة بلا صاحب على وضعها العام، لأن البيانات القديمة لا تسجل سياق المحل الذي أُنشئت منه.

اختبر شاشة مفعلة أعلى وأسفل المحل، وقارن واجهة أوزمان ومحل آخر. اختبارات `ScreenShopIsolationTest` تغطي ربط الشاشة، حدود الصلاحيات، بيانات العرض، واجهات أنواع المحلات، والترحيل من البيانات القديمة.

## نتيجة التحقق

- نجح 14 اختبارًا، مع 163 تحققًا، في `ScreenShopIsolationTest` و`ScreenDisplayTest` و`CosmeticsStoreTest` و`DistributorStorefrontListingTest`.
- فحص Chrome على بيانات محلية منفصلة وبعرض جوال 390 بكسل: ظهرت الصورة العلوية والسفلية في محل Elegance، دون أخطاء JavaScript أو تجاوز أفقي.
- الفحص الأوسع كشف اختبارين قديمين في `AdvertisingStoreTest` و`ElectronicsStoreTest` يتوقعان نصًا حرفيًا لقائمة أنواع المحلات في `public/script.js`؛ الملف لم يتغير بهذا الإصلاح. بقية الاختبارات في ذلك الفحص نجحت، باستثناء مشكلة في قالب العرض الجديد عولجت ثم نجحت اختبارات العزل أعلاه.
- لم تُشغّل عملية الترحيل على قاعدة بيانات الموقع الفعلي ضمن هذا التحقق.
