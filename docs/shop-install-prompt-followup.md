# متابعة عدم ظهور نافذة التثبيت — 2026-10-16

تم فحص الرابط المنشور `https://ozman.online/shop-app/elegance-perfumes/install` باستخدام Chrome بملف فحص منفصل. وصل `beforeinstallprompt` فعلًا، ولم تظهر أخطاء installability أو JavaScript، ونجح تحميل أيقونات PNG بقياسي 192 و512. هذه نتيجة على Chrome المكتبي مع محاكاة قياس الهاتف ووكيل المستخدم؛ ليست تجربة تثبيت Android فعلية.

الرسالة التي تظهر في لقطة المستخدم تعني أن الصفحة لا تملك حدث تثبيت محفوظًا عند الضغط. الصورة وحدها لا تثبت سبب غياب الحدث. النطاق المنشور لتطبيق زبائن Elegance هو `/shop-app/elegance-perfumes/`، ولتطبيق زبائن أوزمان `/shop-app/ozman/`. لكن تطبيق إدارة Elegance ما زال بنطاق `/`، كما كانت النسخ القديمة من تطبيقات الزبائن. وجود تطبيق مثبّت بالنطاق الأوسع قد يمنع حدث التثبيت للمحل. توثيق Google: https://web.dev/articles/building-multiple-pwas-on-the-same-domain

التعديلات الإضافية في هذه الدفعة:

- اكتشاف وضع التطبيق `fullscreen` و`minimal-ui` و`window-controls-overlay` بالإضافة إلى `standalone`، حتى يفتح زر التثبيت Chrome من هذه الحالات أيضًا.
- إضافة معالجة فعلية لتحميل صفحات التنقل في Service Worker، مع صفحة إعادة محاولة عند انقطاع الاتصال، بدون تخزين صفحات المستخدم أو الطلبات. هذا يحسن التوافق مع إصدارات Chrome التي تشترط fetch handler لعرض نافذة التثبيت. نجاح الحدث في المتصفح المفحوص يعني أن غياب المعالج لم يمنعه على تلك النسخة. توثيق Google: https://developer.chrome.com/blog/update-install-criteria
- فحص المتصفح يسجل وصول `beforeinstallprompt` نفسه، بالإضافة إلى فحص manifest.

نجح 12 اختبار JavaScript. هذه التعديلات محلية ولم تُنشر خلال الفحص. تُرفع الملفات الثلاثة `public/shop-pwa.js` و`public/merchant-pwa.js` و`public/merchant-pwa-sw.js`؛ وعند فصل `public_html` يجب تحديث نسخها التي يخدمها الموقع هناك أيضًا. بيانات الطلبات والجلسات واشتراكات الإشعارات لا تُمسح.

للتحقق على الجهاز: افتح Chrome نفسه، الصق رابط التثبيت في شريط العنوان، ثم افحص قائمة ⋮. إذا كانت تعرض فتح التطبيق المثبّت بدل تثبيت تطبيق المحل، افحص تطبيق أوزمان/الإدارة المثبّت بالنطاق الأوسع. لا يمكن للصفحة فرض نافذة تثبيت حين يحجبها المتصفح. لا تمسح بيانات Chrome أو اشتراكات الإشعارات كإجراء تشخيص عام.
