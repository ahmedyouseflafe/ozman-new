# تتبّع توصيل طلبات المطعم

بعد نشر التعديلات شغّل `php artisan migrate`. المندوب يضغط «استلمت الطلب وخرجت للتوصيل»، ثم «بدء مشاركة موقعي مع العميل» ويوافق على إذن الموقع. تظهر إحداثياته للعميل عبر رابط التتبّع الموقّع فقط أثناء حالة «في الطريق»، وتختفي إذا لم تصل إشارة خلال دقيقتين أو عند إيقاف المشاركة أو التسليم أو تغيير المندوب.

لتفعيل الخريطة ومسار الشوارع ووقت الوصول، أنشئ مشروع Google Maps Platform مع فوترة، وفعّل **Maps JavaScript API** و**Routes API** (الخدمة الحديثة، وليس Directions API Legacy). أنشئ مفتاح متصفح مقيّدًا بمراجع HTTP الخاصة بـ `https://ozman.online/*` وبالواجهتين المذكورتين. ضعه في بيئة الخادم باسم `GOOGLE_MAPS_BROWSER_KEY`، ثم شغّل `php artisan config:cache` بعد النشر. لا تضع المفتاح في المستودع.

يُعاد حساب الطريق تقريبًا مرة كل دقيقة أثناء وصول GPS، وقد تخضع الطلبات لرسوم Google. بدون المفتاح لا تُعرض خريطة أو مدة تقديرية غير حقيقية. مشاركة الموقع في المتصفح تتطلب HTTPS وإذنًا من المندوب وبقاء الصفحة قادرة على العمل؛ تتبّع مستمر بعد إغلاق الشاشة أو التطبيق يحتاج تطبيق جوال أصليًا بصلاحية موقع في الخلفية.
